####
SNMP
####

Waarp-Gateway intègre un sous-système SNMP. Ce sous système permet d'envoyer des
notifications à un ou plusieurs agents en cas d'erreur ou d'avarie. Il permet
également à un agent externe de demander certaines information d'analytique sur
le statut de Gateway.

La MIB décrivant ce sous-système SNMP peut être téléchargée
:download:`ici <waarp-gateway.mib>`.
