===========================
Démarrer un filewatcher
===========================

.. program:: waarp-gateway filewatcher start

Démarre le *filewatcher* donné en paramètre.

**Commande**

.. code-block:: shell

   waarp-gateway filewatcher start "<FLOW>"

**Exemple**

.. code-block:: shell

   waarp-gateway filewatcher start 'my-filewatcher'
