==========================
Arrêter un filewatcher
==========================

.. program:: waarp-gateway filewatcher stop

Arrête le *filewatcher* donné en paramètre.

**Commande**

.. code-block:: shell

   waarp-gateway filewatcher stop "<FLOW>"

**Exemple**

.. code-block:: shell

   waarp-gateway filewatcher stop 'my-filewatcher'
