============================
Supprimer un filewatcher
============================

.. program:: waarp-gateway filewatcher delete

Supprime le *filewatcher* donné en paramètre.

**Commande**

.. code-block:: shell

   waarp-gateway filewatcher delete "<FLOW>"

**Exemple**

.. code-block:: shell

   waarp-gateway filewatcher delete 'my-filewatcher'
